# «Следователь» — фабрика испытаний LLM

ИИ-агент номинации «ИИ-проект: Стратег Фабрики продуктов» (МегаФон), MGIMO AI Challenge 2026.

«Следователь» отвечает на вопрос «какую модель взять под эту задачу» данными, а не мнением. Фабрика прогоняет фиксированные тесты через выборку моделей по одинаковым правилам, собирает баллы и время в протокол, из протокола пересобирает routing-таблицу — карту решений, по которой агент работает с новыми задачами.

## Запуск

1. Склонируй репозиторий и открой папку в агентном редакторе — Cursor, opencode или аналог. AGENTS.md подхватится как конституция агента: карта файлов и правила выбора модели.

```
git clone https://github.com/alexprotop302-tech/product-strategist-agent.git
```

2. Дай задачу, например: «Дай продуктовую и коммуникационную стратегию: удержание подписочного сервиса за 3 месяца упало на четверть — вкладываться в удержание или менять упаковку и кому продавать?»
3. Агент классифицирует тип задачи, откроет routing-таблицу, возьмёт рекомендуемую модель и канал, при отказе уйдёт на эскалацию. Ответ сохраняется в answers/ как сырьё.

Все каналы бесплатные: веб-чаты GigaChat и Алисы, шлюз OpenCode для DeepSeek и GLM.

## Маршрут

1. [knowledge/routing.md](knowledge/routing.md) — главный выход фабрики: тип задачи → рекомендуемая модель → канал → эскалация при отказе.
2. [AGENTS.md](AGENTS.md) — конституция агента: карта файлов и правила маршрутизации.
3. [docs/model-eval.md](docs/model-eval.md) — протокол: 16 зачётных прогонов, ключи оценки, время и расход квоты по каждой ячейке.
4. [docs/report.md](docs/report.md) — отчёт цикла: методика, канальные инциденты, выводы.
5. [answers/](/answers) — сырьё: дословные ответы моделей и скриншоты, не редактируются.

## Методика

- Выборка 2×2, бюджет — ноль: две закрытые российские модели в веб-чатах (GigaChat, Алиса) против двух открытых (DeepSeek, GLM) на бесплатном шлюзе агента.
- Одинаковые условия: промпт слово в слово, новый чистый чат на каждый прогон, шкала 0–2 по заранее записанным ключам.
- Честные данные: инциденты каналов фиксируются в журнале отдельно и в баллы не попадают; сырьё хранится как получено.
- Выбор модели — по измеренному: время ответа и расход квоты, с дисквалификацией по правилам и эскалацией при отказе.

## Продолжение после перерыва

Среда агента живёт в файлах, а не в памяти чата: AGENTS.md, routing-таблица, протокол и журнал инцидентов восстанавливают контекст в новом чате без пересказа.
