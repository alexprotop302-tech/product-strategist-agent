# Выборка моделей

Мы сравниваем две альтернативы — закрытые API российских вендоров против открытых моделей на бесплатном шлюзе агента — по два представителя в каждой группе, чтобы отличить закономерность от каприза единичной модели.

## Модель: GigaChat (GigaChat 3.5 Reasoning)
Почему выбрана: флагман российского LLM-рынка, сильный русский язык.
Доступ: бесплатно через giga.chat.
Роль в сравнении: эталон российских закрытых моделей.

## Модель: Яндекс Алиса (YandexGPT, режим "эксперт")
Почему выбрана: второе крупное российское семейство. Нужна, чтобы понять: поведение GigaChat — это закономерность всего российского рынка или особенность одной модели. По одному свидетелю из группы выводов не делают.
Доступ: бесплатно через alice.yandex.ru.
Роль в сравнении: второй российский свидетель.

## Модель: DeepSeek (DeepSeek v4.1 Flash: max)
Почему выбрана: одна из сильнейших открытых моделей мира. Представляет альтернативу закрытым API — а для «Фабрики продуктов» это вопрос стратегии: покупать доступ к чужому API или разворачивать открытое на своих серверах.
Доступ: бесплатный шлюз OpenCode; при лимите шлюза — веб-чат, режим "Глубокое мышление".
Роль в сравнении: планка качества открытых моделей.

## Модель: GLM (GLM-5.3-Flash: high)
Почему выбрана: независимое семейство открытых моделей — лаборатория Z.ai публично выкладывала веса предыдущих версий семейства GLM, что соответствует открытой группе выборки.
Доступ: бесплатно через шлюз OpenCode. 
Роль в сравнении: второе семейство открытой группы.
